SECTION: E101 Overview
PAGE: 2
MACHINE: Press-200
MODEL: P400
ERROR CODE: E101
MEANING: Hydraulic oil pressure low.
CAUSES:
- Hydraulic fluid leak
- Faulty hydraulic pump valve
- Worn pressure seals

SECTION: E101 Troubleshooting
PAGE: 2
MACHINE: Press-200
MODEL: P400
ERROR CODE: E101
STEPS:
1. Shut down Press-200 hydraulic unit.
2. Check hydraulic fluid level gauge on main tank.
3. Inspect main pressure line hoses for visible leaks.
4. Replace seals or top up ISO VG 46 hydraulic oil.

SECTION: E202 Overview
PAGE: 3
MACHINE: Press-200
MODEL: P400
ERROR CODE: E202
MEANING: Emergency stop circuit tripped.
CAUSES:
- Emergency button engaged on control panel
- Safety light curtain obstruction

SECTION: E202 Troubleshooting
PAGE: 3
MACHINE: Press-200
MODEL: P400
ERROR CODE: E202
STEPS:
1. Release all physical E-stop push buttons.
2. Clear perimeter area near safety light curtain sensors.
3. Press master reset button on control box.

SECTION: E203 Overview
PAGE: 4
MACHINE: Press-200
MODEL: P400
ERROR CODE: E203
MEANING: Hydraulic ram alignment fault.
CAUSES:
- Uneven die load distribution
- Guide pillar lubrication failure

SECTION: E203 Troubleshooting
PAGE: 4
MACHINE: Press-200
MODEL: P400
ERROR CODE: E203
STEPS:
1. Inspect die set for improper mounting.
2. Apply heavy-duty grease to guide pillars.
3. Recalibrate stroke sensor zero position.
